About FaceAI

An AI-powered facial analysis system built with Node.js and OpenRouter — running entirely on your local machine.

Features
😊

Emotion Detection

Detects happiness, sadness, anger, surprise and more from facial expressions with confidence scores.

🎂

Age Estimation

Estimates approximate age range purely through AI vision analysis — no external database required.

📊

Confidence Metrics

Percentage-based confidence scores for each detected attribute to help gauge accuracy.

🔒

Secure Auth

Login/Register system with SHA-256 hashed passwords and HttpOnly session cookies.

📝

Analysis History

Every scan is automatically saved. View your complete analysis history anytime from the History page.

⚡

Admin Panel

Full admin dashboard — manage users, view all analyses, block/unblock accounts, and delete users.

How It Works
1

User Registers / Logs In

Account is created with hashed password. Server issues a secure session cookie valid for 24 hours.

2

Image Upload

User selects an image. Browser converts it to base64 — no image is ever stored on the server.

3

Session Verification

Request hits /api/analyze. Server checks the session cookie — if not logged in, returns 401 error.

4

AI Analysis

Server sends image to OpenRouter's free vision model. AI analyzes face and returns structured JSON results.

5

Results Saved & Displayed

Analysis record (emotion, age, gender, confidence) is saved to analyses.json. Results are shown on screen.
